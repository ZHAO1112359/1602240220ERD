# 牙科诊所预约与到诊确认小程序

这是一个完整的微信小程序工程，包含"预约就诊"和"到诊确认"两个用例，可在微信开发者工具中打开运行。

## 一、如何运行

1. 下载并安装 **微信开发者工具**（微信官方，搜索"微信开发者工具"即可）。
2. 打开工具，选择 **导入项目**（或"+"新建 → 导入项目）。
3. 目录选择本文件夹 `miniprogram`。
4. AppID 一栏：
   - 如果你有微信小程序 AppID，直接填入；
   - 如果没有，选择 **"测试号"**（工具会提供一个临时 AppID），或选择"不使用 AppID / 游客模式"——课程作业演示用测试号即可。
5. 点击 **确定 / 编译**，工具会自动编译并在模拟器里运行。

> 后端说明：本工程用小程序本地缓存（`wx.setStorageSync`）模拟数据库持久化，无需搭建服务器或数据库，导入即可运行。首页有"重置演示数据"按钮可恢复初始状态。

## 二、演示流程

首页有两个角色入口：

- **患者端 → 预约就诊**：选医生 → 选日期 → 选时段（已约时段置灰）→ 填姓名手机号 → 提交 → 跳到"我的预约"查看状态。
- **前台端 → 到诊确认**：进入"待确认名单"（系统自动筛出过点未到的记录）→ 点"电话确认" → 选择患者答复（要来 / 改期 / 不来 / 联系不上）→ 状态迁移 → 到"运营统计"查看爽约数与挽回数。

初始演示数据包含 3 条"过点未到"记录和 1 条未来的正常预约。

## 三、工程结构（与设计文档的对应）

```
miniprogram/
├── app.js / app.json / app.wxss      全局配置与样式
├── project.config.json               项目配置（导入用）
├── sitemap.json                      小程序搜索配置
├── utils/
│   ├── store.js                      数据访问层：本地缓存模拟数据库（对应 5 张数据表）
│   └── biz.js                        业务逻辑层：两个控制类 + 状态迁移 + 爽约口径
└── pages/
    ├── index/                        首页（角色入口）
    ├── book/                         患者端：预约就诊（UC-01）
    ├── mine/                         患者端：我的预约
    ├── pending/                      前台端：待确认名单（UC-02）
    ├── confirm/                      前台端：电话确认
    ├── all/                          前台端：全部预约
    └── stats/                        前台端：运营统计看板
```

- `utils/biz.js` 对应设计文档第 6 章的两个控制类：`bookAppointment`（预约就诊控制）、`buildPendingList` + `confirmAppointment`（到诊确认控制）。
- `STATUS_TEXT` / `RESULT_TEXT` 对应状态机图的 7 个状态与 4 种确认结果。
- 爽约口径：只有"不来 / 联系不上"计入爽约，"要来 / 改期"属于挽回，与愿景度量一致。

## 四、说明

- 本工程是课程作业演示原型，数据存在本地缓存，未接入真实数据库与后端服务。
- 业务规则（时段互斥、重复预约拦截、过点未到筛选、状态迁移、爽约口径）均已实现并通过逻辑测试。
- 设计文档见《牙科诊所预约与到诊确认小程序_分析与设计文档》第 5、6 章。
